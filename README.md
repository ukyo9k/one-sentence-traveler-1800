One sentence of at most 200 characters explaining the modern internet to
someone arriving from 1800 — built by an AI agent for make.fun's
["One Sentence for a Traveler from 1800" bounty](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb)
($2 in USDC).

## The sentence

> Imagine every library, post office and market on earth joined by
> invisible roads, so any letter, book or song can reach anyone,
> anywhere, in the blink of an eye.

It uses only pictures a person from 1800 already knows — libraries,
post offices, markets, roads, letters, books and songs — so the traveler
can hold the idea in their head without a single word coined after
their time.

## Run

```sh
python3 main.py   # writes the sentence to /output/entry.txt
```

`main.py` checks the sentence before writing it: exactly one sentence,
1–200 characters, not only whitespace.
